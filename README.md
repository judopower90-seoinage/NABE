# NABE
鍋支度（なべじたく）

おいしい鍋の段取りを、ひと目で。

大鍋イベントにおける「人数換算・買い出し・収支管理・設備安全・現地調理」を一気通貫で支援するスタンドアロンWebアプリケーション。

1. コンセプトと目的

大鍋料理（芋煮会、炊き出し、各種鍋会など）は、家庭料理と異なり以下の課題が複合的に発生します。

参加者の属性（大人・子ども・食べる量）によって実質的な必要量が大きく変動する

食材買い出しの総額と、集金会費との収支（黒字・赤字）の突合が煩雑

大鍋の容量不足による吹きこぼれや、燃料（ガス）不足のトラブル

スーパーの売り場や野外の調理現場など、通信や閲覧環境が不安定な現場での利用

「鍋支度」は、これらの段取りを単一画面上で瞬時に算出し、オフライン環境でも完結して運用できる道具として設計されています。

2. 共通仕様とコアモデル

本アプリケーションは、将来的な料理ジャンルの追加や計算基準の微調整に対応できるよう、以下の共通モジュールで構成されています。

① 人数・食数換算モデル

属性別加重: 参加者区分ごとの消費係数を掛けて基本食数を算出

喫食シーン係数: 他料理との併催やイベント主旨（標準／軽め／主役）に応じた杯数倍率を乗算

換算食数（実効食数）: すべての食材・調味料・必要容量は、この統合指標を基軸に比例計算

② 買い出し・収支管理モデル

食材管理: 食材ごとの単位系（g換算、個数換算）に応じた小計算出とパック目安表示

除外・追加の柔軟性: 持ち寄り食材や不要な具材のチェックON/OFF、独自品目の動的追加

集金・雑費の突合: 会費設定×人数から導く「集金総額」と、「食材小計＋会場・予備費」の差額（黒字／不足）を常時監視

③ 設備・安全基準モデル

大鍋容量の推計: レシピに応じた必要水分量と具材嵩から仕込み総体積を推計し、吹きこぼれ防止の安全余裕（マージン）を加味した推奨鍋サイズを提示

熱源・消耗品推計: 実効食数および総人数に応じたカセットボンベ本数や取り皿・備品の目安算出

④ 現場運用・共有導線

現地調理モード: 調理台や屋外の強い日差しの下でも視認しやすい高コントラスト表示と、工程完了のトグル管理

テキスト共有: 参加者連絡用（LINE、チャットツール等）に整形されたテキストのワンクリック書き出し

データ連携: 外部表計算ツール（Googleスプレッドシート、Excel）からのCSV/TSVコピペ取込

3. システム・動作仕様

アーキテクチャ: 外部サーバーや特定ライブラリに依存しない単一HTMLファイル（HTML5 / CSS3 / Vanilla JS）

動作環境: PC・タブレット・スマートフォンのモダンブラウザ（オフライン動作対応）

状態保持: ブラウザローカル保存（localStorage）による入力状態・進行状況の自動復元

出力対応: A4用紙サイズに最適化した印刷用スタイルシート（Print to PDF）内蔵
